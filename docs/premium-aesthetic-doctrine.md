# Premium Aesthetic Doctrine V3

## Objetivo

Conseguir un lenguaje elegante, tecnológico y didáctico. La calidad percibida debe nacer de jerarquía, proporción, materialidad y precisión; no de acumulación decorativa.

## Sistema

| Elemento | Regla |
|---|---|
| Fondo | Navy casi negro con degradado radial localizado detrás del protagonista; sin bandas llamativas |
| Acento primario | Cyan/teal para estructura, flujo y elementos activos |
| Acento semántico | Lima suave solo para principal, resultado o excepción económica |
| Texto | Blanco roto para claims; azul gris para soporte; contraste mínimo AA |
| Profundidad | Dos niveles: superficie y protagonista; sombra difusa corta y borde luminoso contenido |
| Gradientes | Máximo dos stops visibles; nunca sustituyen jerarquía |
| Conectores | 1–2 px, extremos claros, recorrido corto, sin atravesar labels |
| Cajas | Contener solo relaciones reales; evitar grid de dashboard |
| Tipografía | Sans legible; serif editorial solo cuando el objeto documental lo justifica |
| Protagonista | Mayor área, contraste y nitidez; un único primario por hold |
| Charts/timelines | Tinta baja para estructura; datos activos en acento; labels directos |

## Motion

- Mover para revelar causalidad, identidad o prioridad.
- Combinar opacidad con desplazamiento, escala o trazado; prohibir fade genérico como transición completa.
- Mantener micro-motion finita, subordinada y cancelable.
- Reservar glows para el instante de foco; no dejarlos en loop.
- Terminar siempre en un money frame estable.

## Presupuesto de craft

Aplicar una mejora estética solo si refuerza atención, jerarquía o percepción de calidad. Si el elemento no cambia qué se mira ni cómo se entiende, eliminarlo.

## Antipatrones

- neón dominante;
- glassmorphism sobre cada bloque;
- partículas, parallax o ambient loops sin significado;
- múltiples protagonistas;
- sombras duras o profundidad 3D falsa;
- microtexto usado para conservar densidad;
- cards repetidas como sustituto del diagrama.
