# Fixed Income Foundations V1

Four interactive lessons that transform the approved Block 1 bond artifacts
into a multi-profile learning runtime.

```bash
npm ci
npm run validate
npm run build
npm run e2e
```

Profiles are selected with `?mode=aula`, `?mode=estudio`, or `?mode=video`.
Add `profe=1` for teaching notes and `capture=1` for a clean 16:9 OBS canvas.
Aula/video requests fall back to study mode at widths up to 900 px.

`npm run e2e` uses the production build and all three browser engines. Visual
baselines are intentionally not regenerated by CI; update them only after
opening the rendered output and accepting the change with `npm run e2e:update`.
