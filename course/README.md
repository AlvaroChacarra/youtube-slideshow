# Fixed Income Foundations V1

Four interactive lessons that transform the approved Block 1 bond artifacts
into a multi-profile learning runtime.

## Operating map

- `docs/BASELINE.md` — immutable source and benchmark provenance.
- `docs/TECH_STACK.md` — locked production stack and ownership boundaries.
- `docs/VISUAL_DIRECTION.md` and `docs/MOTION_CONTRACT.md` — design invariants.
- `docs/WORK_STATUS.md` — current implementation and validation state.
- `docs/FINAL_AUDIT.md` — accepted evidence, scores, limitations and verdicts.
- `docs/TEACHING_DRY_RUN.md` — the remaining human teaching/OBS gate.

```bash
npm ci
npm run validate
npm run build
npx playwright install --with-deps
npm run e2e
```

Profiles are selected with `?mode=aula`, `?mode=estudio`, or `?mode=video`.
Add `profe=1` for teaching notes and `capture=1` for a clean 16:9 OBS canvas.
Aula/video requests fall back to study mode at widths up to 900 px.

`npm run e2e` uses the production build and all three browser engines. Visual
baselines are intentionally not regenerated by CI; update them only after
opening the rendered output and accepting the change with `npm run e2e:update`.

GitHub Pages publishes automatically only from a successful `main` Course CI
run. A branch can publish only through the manual workflow with
`publish=true`; pull requests build an artifact without deploying it.
