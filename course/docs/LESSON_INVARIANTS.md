# Invariants extracted after lessons 1 and 2

The shared layer was extracted only after comparing the rendered needs of L1
and L2. V1 keeps exactly these common seams:

| Invariant | Responsibility |
|---|---|
| `SceneFrame` | scene/stage heading, route metadata and dominant visual slot |
| `BondObject` | persistent contractual certificate and scenario controls |
| `CashflowTimeline` | ordered coupons with principal only at maturity |
| `FormulaBuilder` | progressive notation and computed result band |
| scenario controls | reducer-owned financial inputs with pure recalculation |
| lesson navigation | reversible scene/stage traversal and explicit progress |

No generic scene framework, dashboard component set or cross-project design
system was introduced. L3 and L4 compose these seams with domain-specific
reinvestment and market representations.
